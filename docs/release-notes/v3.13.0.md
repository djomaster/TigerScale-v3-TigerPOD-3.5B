# 3.13.0 — fork custom 3.5B, POD 1.0

Personal custom build, not the upstream 3.13 firmware. Historical base:
V3Plus 3.11.0 with the RFID 3.13 port and custom TigerPOD changes.

Automatic spool recognition runs asynchronously without a modal saving screen.
Discovery tolerates short RF dropouts, rejects stale responses after placement
or account changes, and retries failed lookups silently. Weight sampling and
physical NFC confirmation are retained. Sources only; ESP32 build and hardware
validation remain with the user. See `docs/CHANGES-1.0.0.md`.

Reads of the two inventory identities are batched; local discovery waits and
post-read polling pauses are reduced. Sub-second hardware timing is unverified.

The unknown-tag menu uses a short protected NTAG preview and may reuse a just-
completed lookup for the same account/UIDs. Full memory checks still precede
any encoding or formatting; two distinct tags remain mandatory.

TigerPOD is accessible on the weighing home screen, with a single scan action,
tools-back navigation and safe same-action retries. Network OTA is disabled
until an approved custom channel exists. Journal checksums stream without large
String copies; POD responses use bounded PSRAM buffers. Live-view resources are
released during POD and background TLS calls are serialized. Memory admission
checks and reset/stage diagnostics support hardware investigation of the reported
reboots; the cause and the hardware fix remain unverified.
