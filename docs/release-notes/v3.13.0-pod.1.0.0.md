# 3.13.0-pod.1.0.0 — first release of the custom 3.5B build

> Historical notes: the OTA-disabled statements below describe earlier versions. Since `3.13.0-pod.1.1.0`, Settings > Update offers manual updates from this repository’s release assets only, with mandatory SHA-256 verification, no automatic check and no cloud-triggered installation. The owner confirmed hardware tests of the current version on a real Waveshare 3.5B on 2026-11-19; earlier test limitations below remain historical.

Personal build on top of the official 3.13.0 firmware, with the Bambu Lab native-tag support of the 3.11.0 fork, quick battery charging, RFID reader sleep with the screen, and TigerPOD.

- New interface following the design mockups: weigh screen, TigerPOD home as six cards, refreshed palette.
- Native Bambu tags linked to an inventory spool now show brand, material and colour on the weigh screen.
- The Update row is hidden from Settings (this build does not install over the air).
- TigerPOD refresh, verify and restore are hardened against low-memory TLS failures.

Sources only: no ESP32 build or bench validation has been run for this release. See `docs/CHANGES-1.0.0.md`.
