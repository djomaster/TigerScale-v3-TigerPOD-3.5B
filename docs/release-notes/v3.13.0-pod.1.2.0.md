# 3.13.0-pod.1.2.0 — the 3.5 without the B

- New environment `esp32s3_hsu` for the Waveshare ESP32-S3-Touch-LCD-3.5 (no B): same wiring, ST7796 panel over SPI. The web installer offers it and every release publishes both boards.
- Over-the-air updates give each board its own image.
- The 3.5B build is unchanged. The boot screen reads "V3 v3.13.0 - POD v1.2.0".

The 3.5 build compiles and passes the host tests but has not been run on a real 3.5 board; the 3.5B remains the bench-verified one. Flash the image that matches the board's silkscreen: the wrong one gives a black screen.
