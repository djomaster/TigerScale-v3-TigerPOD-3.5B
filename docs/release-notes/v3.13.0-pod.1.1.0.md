# 3.13.0-pod.1.1.0 — over-the-air updates

- Settings > Update works again. Opening it checks this fork's manifest; Install downloads the web UI and the firmware from this repository's GitHub release assets, verifies their SHA-256, then restarts. Wi-Fi, account and calibration are kept.
- Only this repository's release downloads are accepted, a SHA-256 is mandatory, and there is no automatic check and no cloud-triggered update.
- The boot screen reads "V3 v3.13.0 - POD v1.1.0".

Scales running 3.13.0-pod.1.0.0 cannot update themselves: flash this version once over USB or with the web installer. Hardware tests for 3.13.0-pod.1.1.0 were confirmed as validated on a real Waveshare 3.5B scale by the owner on 2026-11-19. This records the owner’s confirmation; no additional tests were run for this documentation update.
